# This Late Hour

A login-gated, text-based mystery/logic-puzzle game — built as a learning project covering auth, databases, cookies, and self-hosted deployment.

See [`plans/initial/DESIGN_NOTES.md`](plans/initial/DESIGN_NOTES.md) for stack decisions, game design, and the data model, and [`plans/initial/LEARNING_GOALS.md`](plans/initial/LEARNING_GOALS.md) for the concepts this project is meant to teach along the way. Newer planning docs live under [`plans/`](plans/).

Stack and case content aren't locked in yet — see "Open decisions" at the bottom of the design notes.
